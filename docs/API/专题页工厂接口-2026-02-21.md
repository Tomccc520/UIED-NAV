# 专题页工厂接口（2026-02-21）

## 1. 能力说明

- 提供专题模板运营能力：模板列表、模板保存、模板删除。
- 提供“一键复制模板创建专题页”能力。
- 内置模板：`AI工具大全`、`设计工具大全`、`跨境工具大全`。

## 2. 后台管理接口

1. `GET /api/uied/topicFactory/template/list`
2. `GET /api/uied/topicFactory/template/detail`
3. `POST /api/uied/topicFactory/template/save`
4. `POST /api/uied/topicFactory/template/del`
5. `GET /api/uied/topicFactory/preview`
6. `POST /api/uied/topicFactory/createFromTemplate`
7. `GET /api/uied/topicFactory/schema`

## 3. 一键创建请求示例

```json
{
  "templateKey": "ai-tools-directory",
  "pageName": "AI工具大全",
  "pageSlug": "ai-tools",
  "categorySlugs": ["ai-xiezuo", "ai-kaifa"],
  "sortOrder": 20
}
```
