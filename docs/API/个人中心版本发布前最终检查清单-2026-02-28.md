## 5. 发布通过标准

### 必须满足

1. 用户中心回归脚本 `FAIL=0`
2. 前端 `npm run build` 成功
3. 商业版健康检查 `FAIL=0`
4. 个人中心手工抽查通过：
   - 登录
   - 我的消息 -> 查看授权
   - 我的授权 -> 自动定位
   - 我的收藏 / 我的点赞 -> 能移除
   - 我的评论 -> 能展开回复链
   - 账号安全 -> 能看到 2FA 状态与设备列表

### 建议满足

1. 历史授权审核消息已执行一次 `--write` 回填
2. 头像上传抽查通过
3. 使用测试账号和你的主账号都各走一遍
