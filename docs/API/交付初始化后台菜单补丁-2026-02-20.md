# 交付初始化后台菜单补丁（2026-02-20）

## 1. 背景

交付初始化向导 API 已上线，但后台缺少独立菜单入口，导致无法直接在管理端执行“一键导入”。

## 2. 本次变更

- 新增后台页面：
  - `server/admin/src/views/uied/deliveryInit/index.vue`
- 新增 SQL 补丁：
  - `server/sql/patch_2026_0220_delivery_init_menu.sql`
- 同步扩展商业版菜单安装脚本：
  - `server/sql/patch_2026_0219_commercial_user_menu.sql`
- 同步菜单组件修复补丁：
  - `server/sql/patch_2026_0220_menu_component_fix.sql`

## 3. 新增菜单与权限

- 页面菜单：
  - `id=894`
  - `menu_name=交付初始化`
  - `perms=uied:delivery:init:index`
  - `component=uied/deliveryInit/index`
  - `selected=/uied/delivery-init`
- 按钮权限：
  - `id=895` `uied:delivery:init:preview`
  - `id=896` `uied:delivery:init:execute`

## 4. 执行方式

```bash
docker exec -i uied_mysql mysql --default-character-set=utf8mb4 -u uied -puied123456 -D uied_nav < server/sql/patch_2026_0220_delivery_init_menu.sql
```

执行后建议重新登录后台，确认路径：

- 菜单：`系统设置 -> 交付初始化`
- 页面地址：`/uied/delivery-init`

## 5. 关联接口

- `ALL /api/uied/delivery/init/preview`
- `ALL /api/uied/delivery/init/execute`
