# 交付初始化向导 API（2026-02-20）

## 1. 目标

提供“一键导入交付基线数据”的后端能力，覆盖：

- 站点配置（siteInfo + setting）
- 导航分类
- 网站标签
- 示例网站
- 文章分类
- 文章标签
- 示例文章
- 许可证（Free/Pro/Enterprise）
- 测试用户

> 适用于商业版客户交付初始化、演示环境初始化、预发布联调环境快速回填。

## 2. 接口清单

### 2.1 预览（不落库）

- `ALL /api/uied/delivery/init/preview`
- 权限标识：`uied:delivery:init:preview`（兼容映射到 `uied:setting:get`）

### 2.2 执行导入

- `ALL /api/uied/delivery/init/execute`
- 权限标识：`uied:delivery:init:execute`（兼容映射到 `uied:setting:save`）

## 3. 执行接口请求示例

```json
{
  "profile": "commercial_default",
  "edition": "pro",
  "brandName": "UIED 商业导航系统",
  "brandDomain": "https://demo.example.com",
  "customerName": "演示客户",
  "companyName": "演示公司",
  "contactEmail": "ops@example.com",
  "domainLimit": 1,
  "domainWhitelist": ["demo.example.com"],
  "includeSiteSettings": true,
  "includeWebsiteCategories": true,
  "includeWebsiteTags": true,
  "includeSampleWebsites": true,
  "includeArticleCategories": true,
  "includeArticleTags": true,
  "includeSampleArticles": true,
  "applyLicense": true,
  "resetFeatureOverrides": true,
  "seedUsers": true
}
```

## 4. 响应示例

```json
{
  "code": 200,
  "data": {
    "profile": "commercial_default",
    "edition": "pro",
    "summary": {
      "siteSettings": {"saved": true},
      "websiteCategories": {"created": 0, "updated": 5},
      "websiteTags": {"created": 0, "updated": 5},
      "sampleWebsites": {"created": 0, "updated": 5},
      "articleCategories": {"created": 0, "updated": 3},
      "articleTags": {"created": 0, "updated": 4},
      "sampleArticles": {"created": 0, "updated": 3},
      "license": {"applied": true, "edition": "pro", "status": "active"},
      "users": {"seeded": true, "total": 4}
    }
  },
  "message": "交付初始化执行成功"
}
```

## 5. 幂等说明

- 接口内部按 `slug` 执行 upsert。
- 重复执行不会重复插入同名数据，会更新并恢复软删除记录。
- 许可证会按最新请求覆盖，功能开关可按参数选择清空或保留。

## 6. 与版本矩阵联动

- `edition` 支持：`free/pro/enterprise`
- 执行时会同步写入许可证中心配置（默认 `active`）。
- 若 `resetFeatureOverrides=true`，会清空覆盖项，改为纯许可证矩阵生效。
