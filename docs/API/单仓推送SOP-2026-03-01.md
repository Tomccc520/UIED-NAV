# 单仓推送 SOP（2026-03-01）

当前项目 `haouied` 已改为单仓结构：

- 根仓：`/Users/tangxiaoda/Desktop/网站备份/HAO UIED`
- 前端目录：`/Users/tangxiaoda/Desktop/网站备份/HAO UIED/frontend`

- GitHub：`github_haouied`
- Gitee：`gitee_haouied`

## 6. 常见错误

### 错误 1：还按旧习惯去 `frontend/` 里单独提交

现象：

- `frontend/` 下没有独立 Git 仓库
- `git status` 报错不是仓库

原因：

- `frontend/` 已经并入根仓

### 错误 2：Gitee 推送失败

现象：

- `403`
- `Oauth: Access token is expired`

原因：

- Gitee HTTPS 凭据已过期

处理：

- 更新 Gitee token，或改用 SSH
