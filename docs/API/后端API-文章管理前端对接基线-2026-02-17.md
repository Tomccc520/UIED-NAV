# 文章管理前端对接 API 基线（后端）

更新时间：2026-02-17
适用范围：官网前端（React）对接文章列表/详情/评论，以及作者投稿中心。

## 1. 当前进度（你可直接同步给前端）

已完成：
- 官网阅读链路已切到内容管理文章库（`la_article`）：
  - `GET /api/articles`（列表）
  - `GET /api/articles/:slug`（详情）
  - `POST /api/articles/:id/view`（阅读+1）
  - `GET /api/articles/:id/comments`（评论列表）
  - `POST /api/articles/:id/comments`（发表评论）
  - `GET /api/articles/meta/categories`（分类元数据）
  - `GET /api/articles/meta/tags`（标签元数据）
- 前台响应归一化已启用（frontend 路由）：统一为 `{ code, data, message }`。
- 作者投稿中心后端接口已具备：`/api/article/front/*`（投稿新增/列表/详情/编辑/审核消息）。

未做（本次不动前端）：
- 官网前端页面逐页接入与交互细节，你这边可按本文档直接对接。

## 2. 响应结构约定（重点）

### 2.1 官网前台路由（`/api/articles*`）
由 `frontend_response_normalizer` 统一处理：
- 成功：`{ code: 0, data: ..., message: "success" }`
- 失败：`{ code: HTTP状态码, data: "", message: "错误信息" }`

### 2.2 系统路由（前台投稿/互动接口）
由 `system_response_normalizer` 归一后返回：
- 成功：`{ code: 0, data: ..., message: "success" }`
- 业务失败：`{ code: 非0, data: ..., message: "错误信息" }`

当前已归一接口：
- `/api/article/front/add`
- `/api/article/front/list`
- `/api/article/front/detail`
- `/api/article/front/edit`
- `/api/article/front/audit/message/list`
- `/api/article/visit/incr`
- `/api/article/collect/list`
- `/api/article/collect/toggle`
- `/api/article/like/toggle`
- `/api/article/stats`
- `/api/article/comment/list`
- `/api/article/comment/add`
- `/api/article/comment/like/toggle`
- `/api/article/comment/report/add`
- `/api/article/comment/top/toggle`
- `/api/user/article/collect/list`
- `/api/user/article/like/list`

其它后台管理接口仍保持 `code=200/300` 兼容格式。

## 3. 鉴权约定

- 公开可读（免登录）：`GET /api/articles*`、`GET /api/articles/:id/comments`
- 需前台用户登录（请求头 `token`）：
  - `POST /api/articles/:id/comments`
  - `/api/article/front/add`
  - `/api/article/front/list`
  - `/api/article/front/detail`
  - `/api/article/front/edit`
  - `/api/article/front/audit/message/list`

说明：上述接口不走后台 admin token，但会在 service 层校验前台用户 token（Redis `user:token:*`）。

## 4. 官网前端优先对接接口（阅读链路）

### 4.1 获取文章列表
- Method: `GET`
- URL: `/api/articles`
- Query:
  - `page` number，默认 `1`
  - `pageSize` number，默认 `10`
  - `category` string，可选（分类名称）
  - `tag` string，可选（标签 slug）
- `data` 示例：

```json
{
  "lists": [
    {
      "id": 12,
      "title": "文章标题",
      "excerpt": "摘要",
      "coverImage": "https://...",
      "author": "作者",
      "category": "产品设计",
      "slug": "12",
      "viewCount": 33,
      "publishedAt": 1739798400000,
      "createdAt": 1739790000000,
      "updatedAt": 1739798400000,
      "tags": [
        { "id": 3, "name": "AI", "slug": "ai", "color": "" }
      ]
    }
  ],
  "total": 100,
  "page": 1,
  "pageSize": 10,
  "totalPages": 10
}
```

### 4.2 获取文章分类元数据
- Method: `GET`
- URL: `/api/articles/meta/categories`
- `data`：`string[]`（分类名称数组）

### 4.3 获取文章标签元数据
- Method: `GET`
- URL: `/api/articles/meta/tags`
- `data` 示例：

```json
[
  { "id": 3, "name": "AI", "slug": "ai", "color": "", "articleCount": 12 }
]
```

### 4.4 获取文章详情
- Method: `GET`
- URL: `/api/articles/:slug`
- 说明：当前 `slug` 基线为文章 ID 字符串（如 `12`），也兼容末尾带数字的 slug。
- `data` 关键字段：
  - `id/title/content/excerpt/coverImage/author/category/slug`
  - `viewCount`
  - `seoTitle/seoDescription`
  - `publishedAt/createdAt/updatedAt`
  - `tags[]`

### 4.5 记录文章阅读
- Method: `POST`
- URL: `/api/articles/:id/view`
- `data`：`{ id, viewCount }`

### 4.6 获取评论列表
- Method: `GET`
- URL: `/api/articles/:id/comments`
- Query：`page`、`pageSize`
- `data`：

```json
{
  "lists": [
    {
      "id": 1,
      "articleId": 12,
      "parentId": 0,
      "isTop": 0,
      "content": "评论内容",
      "userId": 1001,
      "nickname": "Tomda",
      "avatar": "https://...",
      "likeCount": 2,
      "isLike": 0,
      "createTime": "2026-02-17 10:00:00"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 10,
  "totalPages": 1
}
```

### 4.7 发表评论
- Method: `POST`
- URL: `/api/articles/:id/comments`
- Header：`token: <前台用户token>`
- Body：

```json
{
  "text": "评论内容",
  "parentId": 0
}
```

- 成功 `data`：新评论对象（含 `id/commentCount/isShow/autoHidden/interceptReasons`）
- 常见失败：
  - `401`：未登录/登录失效
  - `400`：内容为空、频率限制、禁言等
  - `404`：文章不存在或未发布

## 5. 作者投稿中心接口（可选对接）

注意：这一组已做前台兼容归一，按 `code===0` 判成功。

- `POST /api/article/front/add`：投稿新增（默认待审核）
- `GET /api/article/front/list`：作者自己的投稿列表
- `GET /api/article/front/detail?id=123`：作者自己的投稿详情
- `POST /api/article/front/edit`：作者编辑草稿
- `GET /api/article/front/audit/message/list`：投稿审核通知

## 6. 对接建议（前端）

- 官网阅读页只用 `/api/articles*`，不要混用 `/api/article/*`。
- 统一按 `code === 0` 判成功（本文覆盖的前台文章接口均已归一）。
- 文章详情路由参数按 `slug` 处理，但当前值直接用文章 ID 字符串最稳。
