# 后端排障与商业版菜单修复（2026-02-20）

## 一、修复目标

1. 解决“许可证中心 / 功能开关页面内容重复”
2. 解决文章接口兼容问题（标签序列化异常、slug 详情兼容）
3. 解决 `/api/wordpress/categories/active` 缺表导致的异常
4. 明确用户等级模块用途，避免与“源码购买者账号”混淆

## 二、涉及改动

### 1) 管理后台页面拆分

- 文件：`server/admin/src/views/uied/license/index.vue`
- 变更：
  - 许可证页面仅保留许可证配置
  - 删除页面内重复的“功能开关”表格
  - 增加“前往功能开关”按钮，跳转独立菜单 `/uied/feature-toggle`

### 2) 用户等级用途提示

- 文件：`server/admin/src/views/consumer/level/index.vue`
- 变更：增加页面提示
  - “站点终端用户等级（用于会员权益/功能开关），不是源码购买者账号管理”

### 3) 文章接口兼容修复

- 文件：`server/server/app/controller/uied/frontend.js`
- 变更：
  - 修复文章列表 `tags` 对象被错误字符串化问题
  - 兼容 `slug` 为文本时的详情查询
  - 统一新旧字段映射（`coverImage/cover_image`、`viewCount/visit`、`publishedAt/reviewTime` 等）
  - 标签计数优先走 `uied_article*`，旧结构 `la_article*` 兼容回退

### 4) WordPress 分类缺表兜底

- 文件：`server/server/app/service/uied/wordpressConfig.js`
- 变更：
  - `listCategories` 增加 schema 兼容降级，缺表时返回空数组不再抛 500

### 5) WordPress 数据表补齐

- 新增 SQL：`server/sql/patch_2026_0220_wordpress_tables.sql`
- 新建表：
  - `uied_wordpress_config`
  - `uied_wordpress_category`

### 6) 菜单文案优化

- 新增 SQL：`server/sql/patch_2026_0220_menu_label_refine.sql`
- 变更：
  - 菜单 `id=869` 文案更新为“站点用户等级”

2. WordPress 分类接口：
   - `GET /api/wordpress/categories/active` -> 200（无配置时返回空数组）

3. 菜单映射（数据库）：
   - `864` -> `uied/license/index`
