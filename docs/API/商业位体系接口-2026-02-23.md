# 商业位体系接口（2026-02-23）

## 1. 模块目标

面向售卖版运营场景，提供可配置、可排期、可售卖的商业位体系：

- 置顶位
- 分类内广告位
- 专题赞助位

支持按天/按周售卖，后台配置广告位和投放记录，前台按范围读取生效投放。

## 2. SQL 补丁

1. `server/sql/patch_2026_0223_commercial_slot_tables.sql`
2. `server/sql/patch_2026_0223_commercial_slot_menu.sql`

## 3. 后台接口（需登录）

统一前缀：`/api/uied/commercialSlot`  
说明：后台路由已挂 `operations_blocks` feature guard（Pro 起）。

### 3.1 广告位配置

- `GET /slot/list`
- `POST /slot/save`
- `POST /slot/del`

### 3.2 投放记录

- `GET /booking/list`
- `POST /booking/save`
- `POST /booking/del`

### 3.3 字段草案

- `GET /schema`

## 4. 前台公开接口

- `GET /api/commercial/placements`
- 兼容：`GET /commercial/placements`

### 常用参数

- `slotKey`：广告位键（如 `home-top-pinned`）
- `slotType`：广告位类型（`top` / `category_ad` / `topic_sponsor`）
- `scopeType`：范围类型（`global` / `home` / `category` / `topic`）
- `scopeValue`：范围值（如分类 slug / 专题 slug）
- `limit`：返回数量

## 5. 首版交付范围（已实现）

1. 广告位配置与投放记录后台管理
2. 投放记录时间窗过滤（开始/结束时间）
3. 前台公开读取当前生效投放（状态 + 显示开关 + 排期）
4. 菜单与权限补丁（超级管理员自动授权）
