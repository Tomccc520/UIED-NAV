## 6. 后台“两个用户列表”说明

当前后台是两套用户数据，不是同一张表：

- `管理员`（权限管理 > 管理员）
  - 菜单权限：`system:admin:list`
  - 页面：`permission/admin/index`
  - 数据表：`la_system_auth_admin`
- `用户列表`（用户中心 > 用户列表）
  - 菜单权限：`user:list`
  - 页面：`consumer/lists/index`
  - 数据表：`la_user`

本次新增测试用户都在 `la_user`，所以需要在“用户中心 > 用户列表”中查看，而不是“权限管理 > 管理员”。
