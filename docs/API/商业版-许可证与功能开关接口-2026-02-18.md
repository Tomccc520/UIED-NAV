# 商业版许可证与功能开关接口（2026-02-18）

## 1. 接口清单

- `ALL /api/uied/license/info`：获取许可证信息（免登录）
- `ALL /api/uied/license/save`：保存许可证信息（后台管理）
- `ALL /api/uied/feature/list`：获取功能清单与启用状态（免登录）
- `ALL /api/uied/feature/check`：检查单个功能可用性（免登录）
- `ALL /api/uied/feature/save`：保存功能开关覆盖（后台管理）

## 2. 核心规则

- 版本矩阵：`free / pro / enterprise`
- 能力优先级：`许可证能力 > 后台开关（仅关闭） > 默认能力`
- 许可证失效（过期或状态非 active）时自动降级到 `free`

## 3. 前端对接建议

- 页面初始化时并行请求：
  - `GET /api/uied/license/info`
  - `GET /api/uied/feature/list`
- 封装 `hasFeature(key)`：
  - 方案 A：直接从 `feature/list.rows` 读取
  - 方案 B：按需调用 `GET /api/uied/feature/check?key=xxx`

## 5. 配置存储

当前存储在 `uied_site_setting`：

- `license_center_info`：许可证信息
- `license_feature_overrides`：功能开关覆盖
