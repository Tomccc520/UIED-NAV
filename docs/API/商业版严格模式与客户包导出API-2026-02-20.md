# 商业版严格模式与客户包导出 API（2026-02-20）

## 1. 新增接口

- `ALL /api/uied/delivery/package/export`  
  导出客户包（站点配置 + 分类标签 + 许可证 + 功能开关 + 商业模式）
- `ALL /api/uied/commercial/mode/get`  
  获取商业版模式配置
- `ALL /api/uied/commercial/mode/save`  
  保存商业版模式配置

## 2. 参数说明

### 2.1 `/api/uied/delivery/package/export`

- `includeWebsiteData`：`true/false`，是否额外导出站点数据（默认 `false`）
- `includeArticleData`：`true/false`，是否额外导出文章数据（默认 `false`）
- `download`：`true/false`，是否按附件下载（默认返回 JSON 数据）

### 2.2 `/api/uied/commercial/mode/save`

- `strictLegacyRoutes`：是否启用严格商业版模式（关闭旧兼容路由）
- `enforceLicenseSignature`：是否强制许可证签名校验

## 3. 商业模式行为

- `strictLegacyRoutes = false`：保留旧兼容路由（如 `/articles`）
- `strictLegacyRoutes = true`：旧兼容路由返回 404，仅允许 `/api/*` 正式路由

## 4. 许可证签名校验

- 保存许可证时自动写入 `signVersion` 与 `signature`。
- 读取许可证时执行 HMAC-SHA256 校验。
- 当 `enforceLicenseSignature=true` 且签名无效时：
  - `license.status = invalid_signature`
  - 能力自动降级为 `Free`
