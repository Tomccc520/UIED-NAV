# 商业版发布前健康检查脚本（2026-02-20）

## 1. 目标

在发布售卖版（Free/Pro/Enterprise）前，统一检查：

- 接口可用性（前台公开接口）
- 菜单权限结构（关键 perms + 详情路由挂载）
- 资源完整性（默认头像路径/文件）
- 配置回读（数据库配置 -> `/api/settings/public` 返回一致性）
- 基础数据（测试用户/文章数据）

## 2. 脚本位置

- `scripts/commercial-preflight-check.js`

## 3. 运行方式

```bash
node scripts/commercial-preflight-check.js
```

可选参数：

```bash
node scripts/commercial-preflight-check.js \
  --base-url http://127.0.0.1:8002 \
  --mysql-container uied_mysql \
  --db-user uied \
  --db-pass uied123456 \
  --db-name uied_nav
```

## 4. 报告输出

- 终端输出：按 `PASS/WARN/FAIL` 列出明细
- JSON 报告：`docs/API/reports/commercial_preflight_latest.json`

## 5. 已知告警解释

### 5.1 `菜单重复权限点`

- 告警含义：`la_system_auth_menu` 中存在重复 `perms`
- 当前已知一组：`article:cate:change`（菜单 ID `822, 828`）
- 影响：通常不会导致接口失败，但可能造成权限语义不清晰

### 5.2 `关键配置项缺失 articleConfig`

- 告警含义：`uied_site_setting` 中还未落库 `articleConfig`
- 影响：接口会回退默认值，功能可用但不利于交付一致性
- 建议：后台“站点设置 -> 文章配置”保存一次，触发落库
