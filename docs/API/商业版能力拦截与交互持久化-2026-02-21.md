# 商业版能力拦截与交互持久化（2026-02-21）

## 1. 变更摘要

本次后端补齐了以下 P0 能力：

1. 网站评分与收藏改为真实持久化，不再是兼容空实现。
2. WordPress 标签与组件接口改为数据库配置读取，不再固定空数组。
3. 新增商业版功能守卫中间件，按 `featureKey` 统一返回 403。
4. 修复 AI 配置详情 API 漂移：保留 `/api/uied/aiConfig/detail` 兼容别名，主路径为 `/api/uied/aiConfig/get`。

## 2. SQL 补丁执行顺序（交付初始化）

请按以下顺序执行（均可重复执行）：

1. `server/sql/patch_2026_0221_website_interaction_tables.sql`
2. `server/sql/patch_2026_0221_wordpress_tag_widget_tables.sql`

说明：

- 第 1 个补丁创建网站评分/收藏表。
- 第 2 个补丁创建 WordPress 标签/组件配置表。

## 3. 新增/增强接口

### 3.1 前台公开接口（路径不变）

1. `POST /api/websites/:id/rate`：评分写入 `uied_website_rating`。
2. `POST /api/websites/:id/favorite`：收藏写入 `uied_website_favorite`。
3. `DELETE /api/websites/:id/favorite`：取消收藏（软删除）。
4. `GET /api/wordpress/tags`：返回 WordPress 标签配置。
5. `GET /api/wordpress/widgets/active`：返回 WordPress 组件配置。

### 3.2 后台管理接口（新增）

1. `GET /api/uied/wordpress/tags`
2. `POST /api/uied/wordpress/tags/add`
3. `POST /api/uied/wordpress/tags/edit`
4. `POST /api/uied/wordpress/tags/del`
5. `GET /api/uied/wordpress/widgets`
6. `POST /api/uied/wordpress/widgets/add`
7. `POST /api/uied/wordpress/widgets/edit`
8. `POST /api/uied/wordpress/widgets/del`

### 3.3 AI 配置详情兼容

1. 主路径：`GET /api/uied/aiConfig/get`
2. 兼容别名：`GET /api/uied/aiConfig/detail`
3. Admin API 已统一改为 `/uied/aiConfig/get`
