# 商业版许可证签发、验签与总览 API（2026-02-21）

## 1. 新增接口

- `ALL /api/uied/license/sign`：签发许可证（生成签名，不落库）
- `ALL /api/uied/license/verify`：校验许可证签名（导入前验签）
- `ALL /api/uied/commercial/overview`：商业版总览（许可证/功能/数据量/菜单重复诊断）

## 2. 权限映射

- `uied:license:sign` -> 复用 `uied:setting:save`
- `uied:license:verify` -> 复用 `uied:setting:get`
- `uied:commercial:overview` -> 复用 `uied:setting:get`

## 3. 请求示例

### 3.1 签发许可证

`POST /api/uied/license/sign`

```json
{
  "edition": "pro",
  "status": "active",
  "licenseKey": "UIED-PRO-2026-0001",
  "customerName": "Tomda",
  "companyName": "Tomda Studio",
  "contactEmail": "contact@example.com",
  "domainLimit": 3,
  "domainWhitelist": ["a.com", "b.com"],
  "issuedAt": 1766592000,
  "expiresAt": 1798128000
}
```

### 3.2 校验许可证

`POST /api/uied/license/verify`

```json
{
  "edition": "pro",
  "status": "active",
  "licenseKey": "UIED-PRO-2026-0001",
  "customerName": "Tomda",
  "companyName": "Tomda Studio",
  "contactEmail": "contact@example.com",
  "domainLimit": 3,
  "domainWhitelist": ["a.com", "b.com"],
  "issuedAt": 1766592000,
  "expiresAt": 1798128000,
  "signVersion": "v1",
  "signature": "xxxxxx"
}
```

### 3.3 商业版总览

`GET /api/uied/commercial/overview`

返回字段包含：

- `score`：健康分（0-100）
- `level`：`ready | attention | risk`
- `checks`：检查项（许可证生效、严格模式、签名强校验、文章模块、测试用户、菜单重复）
- `license`：当前许可证摘要
- `commercialMode`：商业模式开关
- `featureSummary`：能力开关统计
- `dataStats`：网站/文章/用户等数据量
- `diagnostics.duplicateMenuPerms`：重复菜单权限诊断

## 4. 使用建议

- 客户发放流程：先调用 `license/sign` 生成签名，再调用 `license/save` 入库。
- 客户导入流程：先调用 `license/verify` 验签通过，再执行保存或导入。
- 发布前检查：后台发布前固定调用 `commercial/overview`，以 `score` 与 `checks` 作为验收门槛。
