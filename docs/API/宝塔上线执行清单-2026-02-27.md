# 宝塔上线执行清单（2026-02-27）

## 1. 服务器基础环境

1. 安装 `Nginx`、`Node.js(18/20)`、`PM2`、`MySQL 8.x`、`Redis`
2. 建议目录：
   - `/www/wwwroot/hao.uied.cn/frontend`
   - `/www/wwwroot/hao.uied.cn/admin`
   - `/www/wwwroot/hao.uied.cn/backend`

## 2. 本地构建静态文件

在本地项目根目录执行：

```bash
cd "/Users/tangxiaoda/Desktop/网站备份/HAO UIED"
chmod +x ./scripts/build-bt-static.sh
./scripts/build-bt-static.sh hao.uied.cn
```

构建产物会输出到：

```text
release/static_YYYYMMDD_HHMMSS/
  frontend/
  admin/
  manifest.txt
```

## 3. 数据库初始化

```bash
# 1) 导入基础表
mysql -h 127.0.0.1 -P 3306 -u <db_user> -p<db_pass> <db_name> < server/sql/install.sql

# 2) 导入业务表
mysql -h 127.0.0.1 -P 3306 -u <db_user> -p<db_pass> <db_name> < server/sql/uied_tables.sql

# 3) 按需执行 patch（已在开发环境执行过的可跳过）
```

## 4. 后端上线

1. 上传 `server/server` 到 `/www/wwwroot/hao.uied.cn/backend`
2. 在后端目录创建 `config/config.prod.js`（参考 `config.prod.example.js`）
3. 启动：

```bash
cd /www/wwwroot/hao.uied.cn/backend
npm install --production
npm run stop || true
npm run start
```

或使用 PM2：

```bash
cd /www/wwwroot/hao.uied.cn/backend
pm2 start npm --name uied-api -- start
pm2 save
```

## 5. 前端与后台静态资源上线

1. 上传 `release/static_xxx/frontend/*` 到宝塔站点根目录（前台）
2. 上传 `release/static_xxx/admin/*` 到 `/www/wwwroot/hao.uied.cn/admin`

## 6. Nginx 关键配置

```nginx
location /api {
    proxy_pass http://127.0.0.1:8002;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location /admin {
    alias /www/wwwroot/hao.uied.cn/admin;
    index index.html;
    try_files $uri $uri/ /admin/index.html;
}

location / {
    root /www/wwwroot/hao.uied.cn/frontend;
    index index.html;
    try_files $uri $uri/ /index.html;
}
```
