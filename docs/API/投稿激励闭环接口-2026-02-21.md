# 投稿激励闭环接口（2026-02-21）

## 1. 模块目标

为“投稿 -> 审核 -> 推荐 -> 激励”建立完整后端闭环，支持商业版后台运营：

- 投稿积分规则可配置
- 勋章自动授予
- 优质投稿推荐位运营
- 用户激励数据可查询

## 2. SQL 补丁

1. `server/sql/patch_2026_0221_contribution_tables.sql`
2. `server/sql/patch_2026_0221_contribution_menu.sql`

## 3. 后台管理接口（需登录）

统一前缀：`/api/uied/contribution`

1. 设置
- `GET /settings/get`
- `POST /settings/save`

2. 勋章
- `GET /badge/list`
- `POST /badge/save`
- `POST /badge/del`

3. 推荐位
- `GET /featured/list`
- `POST /featured/save`
- `POST /featured/del`

4. 用户激励
- `GET /user/list`
- `GET /user/detail`

5. 日志与草案
- `GET /log/list`
- `GET /leaderboard`
- `GET /schema`

## 4. 前台公开接口

1. 投稿排行榜
- `GET /api/contribution/leaderboard`
- 兼容：`GET /contribution/leaderboard`

2. 优质投稿推荐位
- `GET /api/contribution/featured-submissions`
- 兼容：`GET /contribution/featured-submissions`

## 5. 与投稿审核链路联动

位于：`server/server/app/service/article.js`

1. 投稿提交奖励
- `frontAdd` 成功后触发 `rewardSubmissionCreated`

2. 审核通过奖励
- `frontAudit` 且 `reviewStatus=2` 时触发 `rewardSubmissionPublished`

说明：奖励触发采用“旁路失败不阻断主流程”，避免积分异常影响投稿与审核主链路。
