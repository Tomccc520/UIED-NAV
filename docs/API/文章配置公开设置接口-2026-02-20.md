# 文章配置公开设置接口（2026-02-20）

## 1. 背景

为支持“前端官网文章模块可由后台系统设置配置”，本次在后端补齐：

- 公开设置聚合返回中的文章配置字段（`/api/settings/public`）
- 管理端专用的文章配置读写接口（`/api/uied/setting/*`）

## 2. 新增接口（管理端）

### 2.1 获取文章配置

- `ALL /api/uied/setting/articleConfig`
- 权限：`uied:setting:articleConfig`（兼容映射到 `uied:setting:get`）

返回示例：

```json
{
  "code": 1,
  "data": {
    "enabled": true,
    "homeSectionEnabled": true,
    "homeSectionTitle": "设计文章",
    "homeSectionSubtitle": "汇聚优质设计文章，分享前沿设计趋势与实战经验",
    "homeSectionLimit": 12,
    "listPageTitle": "设计专栏",
    "listPageDescription": "汇聚优质设计文章，分享前沿设计趋势、实战技巧与行业洞察",
    "listPageCoverImage": "",
    "commentsEnabled": true,
    "topicsEnabled": true
  },
  "msg": "success",
  "show": 1
}
```

### 2.2 保存文章配置

- `ALL /api/uied/setting/saveArticleConfig`
- 权限：`uied:setting:saveArticleConfig`（兼容映射到 `uied:setting:save`）

请求示例：

```json
{
  "enabled": true,
  "homeSectionEnabled": true,
  "homeSectionTitle": "设计灵感",
  "homeSectionLimit": 8,
  "listPageTitle": "设计专题",
  "listPageDescription": "最新设计内容合集",
  "commentsEnabled": false,
  "topicsEnabled": true
}
```

### 2.3 获取文章专题配置

- `ALL /api/uied/setting/articleTopicsConfig`
- 权限：`uied:setting:articleTopicsConfig`

返回示例：

```json
{
  "code": 1,
  "data": {
    "ui-design": {
      "id": "ui-design",
      "type": "category",
      "title": "UI 设计",
      "description": "探索用户界面设计实践",
      "coverImage": "",
      "icon": "🎨",
      "themeColor": "#3b82f6"
    }
  },
  "msg": "success",
  "show": 1
}
```

### 2.4 保存文章专题配置

- `ALL /api/uied/setting/saveArticleTopicsConfig`
- 权限：`uied:setting:saveArticleTopicsConfig`

请求体为对象，key 为 `category/tag slug`，value 为专题配置对象。

## 3. 公开接口扩展（前端官网读取）

`GET /api/settings/public` 与 `GET /uied/setting/public` 现已新增字段：

- `article`
- `articleTopics`

说明：前端官网可直接在公开设置中读取上述字段，无需额外管理端鉴权。
