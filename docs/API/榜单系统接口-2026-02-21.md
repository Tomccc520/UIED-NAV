# 榜单系统接口（2026-02-21）

## 1. 能力说明

- 支持四类榜单：`today_hot`、`seven_day_rising`、`new_sites`、`editor_pick`。
- 支持后台可运营配置：启用开关、排序、默认条数、榜单名称与描述。
- 支持前台公开读取，适配商业售卖版。

## 2. 前台公开接口

1. `GET /api/rankings`（兼容：`GET /rankings`）
2. `GET /api/rankings/:key`（兼容：`GET /rankings/:key`）

参数：

1. `boardKey`（可选，指定单榜）
2. `limit`（可选，每榜条数）

## 3. 后台管理接口

1. `GET /api/uied/rankBoard/config/list`
2. `POST /api/uied/rankBoard/config/save`
3. `GET /api/uied/rankBoard/list`
4. `GET /api/uied/rankBoard/preview`
5. `GET /api/uied/rankBoard/schema`

## 4. SQL 补丁

1. `server/sql/patch_2026_0221_rank_board_tables.sql`
2. `server/sql/patch_2026_0221_rank_board_menu.sql`

## 5. 后台菜单

- 菜单名称：`榜单系统`
- 菜单图标：`el-icon-Histogram`
- 菜单路径：`rank-board`
- 页面组件：`uied/rankBoard/index`
