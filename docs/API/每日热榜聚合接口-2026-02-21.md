# 每日热榜聚合接口（2026-02-21）

## 1. 能力说明

- 对接第三方源：`https://api.pearktrue.cn/api/dailyhot/`
- 支持后台配置：启用开关、默认平台、缓存时长、超时配置。
- 支持平台级持久化配置：平台开关、排序、缓存策略、超时与条数。
- 支持前台聚合接口与后台管理接口。

## 2. 前台公开接口

### 2.1 获取今日热榜聚合

- `GET /api/daily-hot`
- 兼容路径：`GET /daily-hot`

请求参数：

1. `title`：单个平台标题（可选）
2. `titles`：多平台标题（可选，逗号分隔）
3. `limit`：每个平台返回条数（可选，默认配置值）
4. `platformLimit`：最多聚合平台数（可选）
5. `refresh`：`1` 强制刷新缓存（可选）

### 2.2 获取平台列表

- `GET /api/daily-hot/platforms`
- 兼容路径：`GET /daily-hot/platforms`

请求参数：

1. `refresh`：`1` 强制刷新缓存（可选）

## 3. 后台管理接口

### 3.1 配置

1. `GET /api/uied/dailyHot/config/get`
2. `POST /api/uied/dailyHot/config/save`

配置字段：

1. `enabled`：是否启用
2. `apiBaseUrl`：第三方接口地址
3. `timeoutMs`：请求超时（毫秒）
4. `cacheTtlSeconds`：缓存秒数
5. `defaultPlatforms`：默认平台数组
6. `defaultLimit`：默认每平台返回条数
7. `maxPlatforms`：最多聚合平台数

### 3.2 数据

1. `GET /api/uied/dailyHot/platforms`
2. `GET /api/uied/dailyHot/list`
3. `GET /api/uied/dailyHot/refresh`

### 3.3 平台配置持久化（新增）

1. `GET /api/uied/dailyHot/platformConfig/list`
2. `POST /api/uied/dailyHot/platformConfig/save`
3. `POST /api/uied/dailyHot/platformConfig/del`
4. `GET /api/uied/dailyHot/schema`

`platformConfig/save` 请求示例：

```json
{
  "clearMissing": false,
  "list": [
    {
      "platformTitle": "哔哩哔哩",
      "displayName": "B站",
      "isEnabled": true,
      "sort": 10,
      "cacheTtlSeconds": 600,
      "limitCount": 10,
      "requestTimeoutMs": 12000
    }
  ]
}
```

`schema` 返回字段草案：

1. 全局字段：`enabled/apiBaseUrl/timeoutMs/cacheTtlSeconds/defaultLimit/maxPlatforms/defaultPlatforms`
2. 平台字段：`platformTitle/displayName/isEnabled/sort/cacheTtlSeconds/limitCount/requestTimeoutMs`
3. 缓存策略：`global + platform 双层缓存`

## 4. 后台菜单与权限

SQL 补丁：

1. `server/sql/patch_2026_0221_daily_hot_menu.sql`
2. `server/sql/patch_2026_0221_daily_hot_persistence.sql`
3. `server/sql/patch_2026_0221_daily_hot_menu_upgrade.sql`

推荐执行顺序：

1. 先执行 `patch_2026_0221_daily_hot_menu.sql`
2. 再执行 `patch_2026_0221_daily_hot_persistence.sql`
3. 最后执行 `patch_2026_0221_daily_hot_menu_upgrade.sql`

4. `uied:dailyHot:platforms`
5. `uied:dailyHot:list`
6. `uied:dailyHot:refresh`
7. `uied:dailyHot:platformConfig:list`
8. `uied:dailyHot:platformConfig:save`
9. `uied:dailyHot:platformConfig:del`
10. `uied:dailyHot:schema`

## 5. 说明

- 每日热榜能力默认归为 Free 可用，不做版本拦截。
- 若第三方接口失败，会返回平台级错误，不影响其他平台数据返回。
- 新增持久化表：`uied_daily_hot_config`、`uied_daily_hot_platform`。
