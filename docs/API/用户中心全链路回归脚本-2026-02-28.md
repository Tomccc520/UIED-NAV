# 用户中心全链路回归脚本（2026-02-28）

## 脚本位置

- `/Users/tangxiaoda/Desktop/网站备份/HAO UIED/scripts/user-center-regression-check.js`

## 目标

用于发布前一键验证用户中心核心链路是否可用，覆盖：

- 登录 / 登录 2FA
- 个人资料
- 概览统计
- 订单 / 授权 / 消息
- 收藏 / 点赞 / 评论
- 2FA 状态
- 登录设备列表
- 可选：头像上传
- 可选：设备下线

## 使用方式

### 基础只读回归

```bash
cd "/Users/tangxiaoda/Desktop/网站备份/HAO UIED"
node scripts/user-center-regression-check.js \
  --base-url http://127.0.0.1:8002 \
  --username tomda \
  --password 123456
```

### 包含头像上传验证

```bash
cd "/Users/tangxiaoda/Desktop/网站备份/HAO UIED"
node scripts/user-center-regression-check.js \
  --base-url http://127.0.0.1:8002 \
  --username tomda \
  --password 123456 \
  --avatar-file "/Users/tangxiaoda/Desktop/test-avatar.png"
```

### 登录启用 2FA 时

```bash
cd "/Users/tangxiaoda/Desktop/网站备份/HAO UIED"
node scripts/user-center-regression-check.js \
  --base-url http://127.0.0.1:8002 \
  --username tomda \
  --password 123456 \
  --two-factor-code 123456
```

### 额外验证设备下线

```bash
cd "/Users/tangxiaoda/Desktop/网站备份/HAO UIED"
node scripts/user-center-regression-check.js \
  --base-url http://127.0.0.1:8002 \
  --username tomda \
  --password 123456 \
  --kick-token "待下线的 token"
```

## 输出结果

- 控制台输出：按 `PASS / WARN / FAIL` 列出每个检查项
- JSON 报告：默认输出到  
  `/Users/tangxiaoda/Desktop/网站备份/HAO UIED/docs/API/reports/user_center_regression_latest.json`

## 当前约定

1. 默认只做“安全读检查”，不会主动改动收藏、点赞、评论数据。
2. `--avatar-file` 属于写操作，会上传并更新当前用户头像。
3. `--kick-token` 属于写操作，会下线指定设备。
4. 若登录返回 `need2fa=true`，必须补 `--two-factor-code`。

## 建议发布流程

1. 启动后端 API（`8002`）并确认数据库已连接。
2. 使用测试账号先跑一次基础只读回归。
3. 使用图片文件再跑一次头像上传验证。
4. 需要验收设备下线时，再增加 `--kick-token` 单独验证。
5. `FAIL=0` 后再进入打包或上线。
