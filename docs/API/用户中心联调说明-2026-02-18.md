## 3. 兼容降级说明

当前后端在“商业模块模型缺失（Order/License/Wallet/LoginLog）”时，已对部分接口做降级，避免 500：

- `index/stats`：缺模型时 `orderCount`、`licenseCount` 返回 `0`
- `order/list`、`license/list`、`login/log`：缺模型时返回空列表
- `walletInfo`、`walletLog`：缺模型时返回默认值/空列表
- `walletRecharge`：缺模型时返回“钱包模块未启用”
