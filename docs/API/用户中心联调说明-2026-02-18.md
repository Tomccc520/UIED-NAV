## 9. 登录接口对接规范（本次新增）

- `POST /api/user/register`
  - 入参：`username`(必填) / `password`(必填) / `confirmPassword`(可选) / `nickname`(可选) / `mobile`(可选)
  - 出参：`{ token, user, userInfo }`（`user` 与 `userInfo` 同结构，均为脱敏用户信息）
- `POST /api/user/login`
  - 入参：`username` 或 `account`（二选一） + `password`
  - 出参：`{ token, user, userInfo }`
- `POST /api/user/logout`
  - 功能：注销当前登录态（仅清理当前 token）
- `GET /api/user/profile`
  - 出参：脱敏用户信息，附带 `profileCompletion`、`userType`、`userTypeName`

鉴权头兼容说明：

- 优先读取 `token: <token>`
- 同时兼容 `Authorization: Bearer <token>`
