# 用户中心详情与资源 URL 修复（2026-02-20）

## 1. 修复范围

- 用户列表注册时间显示（由时间戳改为标准时间字符串）
- 用户详情页点击无响应（`user:detail` 菜单路由挂载关系修复）
- 默认头像地址异常（`/api/uploads/api/static/default_avatar.png`）
- 手机号脱敏（列表/详情展示统一脱敏）

## 2. 后端改动

### 2.1 用户列表/详情字段规范化

文件：
- `server/server/app/service/user.js`

新增与调整：
- 新增方法：
  - `getSexLabel`
  - `getChannelLabel`
  - `formatUnixTime`
  - `getMaskedMobile`
- `list` 返回新增/修正字段：
  - `mobileMask`
  - `sexName`
  - `channelName`
  - `createTimeRaw` / `lastLoginTimeRaw`
  - `createTime` / `lastLoginTime`（格式化后）
- `detail` 返回新增/修正字段：
  - `mobileMask`
  - `sexName`
  - `channelName`
  - `createTimeRaw` / `lastLoginTimeRaw`
  - `createTime` / `lastLoginTime`（格式化后）
- `addressList` 增加模型存在判断，缺少 `UserAddress` 模型时返回空列表，不抛异常。

### 2.2 静态资源 URL 组装修复

文件：
- `server/server/app/util/urlUtil.js`

修复点：
- `/api/static/*` 不再错误拼接到 `/api/uploads/*` 下。
- `/api/uploads/*`、`/public/uploads/*` 识别为已是资源路径，直接拼域名。
- 外链 `http(s)://` 直接透传，不重复处理。

## 3. 管理后台改动

### 3.1 用户列表页

文件：
- `server/admin/src/views/consumer/lists/index.vue`

改动：
- 手机号列改为 `mobileMask`
- 性别列改为 `sexName`
- 来源优先显示 `channelName`
- 详情路由增加兼容处理（旧错误路由自动纠偏）
- 去掉重复初始化请求，仅保留 `onActivated` 拉取，避免 `ERR_CANCELED` 未处理报错

### 3.2 用户详情页

文件：
- `server/admin/src/views/consumer/lists/detail.vue`

改动：
- 联系电话展示改为脱敏值 `mobileMask`
- 详情页补充用户类型、等级、分组、标签、最后登录 IP 等信息

## 4. 数据库菜单补丁

文件：
- `server/sql/patch_2026_0220_user_detail_route_fix.sql`

作用：
- 修复 `la_system_auth_menu.id=862`（`user:detail`）错误挂载：
  - 从 `pid=861` 调整为 `pid=860`
  - 保持隐藏路由并设置 `selected` 到用户列表页

执行命令：

