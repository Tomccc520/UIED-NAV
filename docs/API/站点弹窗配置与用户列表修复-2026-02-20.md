# 站点弹窗配置与用户列表修复（2026-02-20）

## 1. 站点设置新增“弹窗可配置项”

### 1.1 配置项

在“站点设置 -> 跳转提醒”新增：

- `logo`：弹窗 logo
- `showAgreementLinks`：是否展示协议链接
- `userAgreementText`：用户协议文案
- `userAgreementUrl`：用户协议链接
- `copyrightAgreementText`：版权协议文案
- `copyrightAgreementUrl`：版权协议链接

### 1.2 接口返回

以下公开接口已支持上述字段：

- `GET /api/settings/public`
  - `data.exitModal`
  - `data.popup`（新增别名，便于前端按“popup”语义读取）
- `GET /api/settings/frontend-config`
  - `exitModalConfig`
  - `popupConfig`（新增别名）

### 1.3 后端处理规则

- `exitModalConfig` 保存时会做统一归一化：
  - `countdown` 限制为 `1~30`
  - 协议文案与链接兜底为字符串
  - `showAgreementLinks` 强制布尔值

## 2. 用户列表无数据排查与修复

### 2.1 已确认事实

- 数据库存在测试用户（`la_user`）：不是“没入库”。
- 用户中心菜单不是两套重复入口，本次已统一文案避免误解。

### 2.2 本次改动

- 用户列表页新增按钮：`初始化测试用户`（接口：`POST /api/user/seed/testUsers`）
- 初始化结果显示“新增/更新”数量，避免误判“重复数据 bug”
- 用户列表页补充字段：
  - `用户类型`
  - `用户等级`
  - `注册来源`改为可读文案
- 菜单文案修复 SQL：
  - `server/sql/patch_2026_0220_consumer_menu_alias.sql`
  - `860 -> 站点用户中心`
  - `861 -> 站点用户列表`
  - `869 -> 站点用户等级`

### 2.3 根因补充（模型字段映射）

- `la_user` 表是下划线字段（如：`real_name/is_delete/create_time`）。
- `server/server/app/model/user.js` 之前缺少部分驼峰字段的 `field` 映射，导致 ORM 查询条件可能命中错误列名。
- 已补齐以下映射并关闭自动时间戳字段：
  - `realName -> real_name`
  - `isDisable -> is_disable`
  - `isDelete -> is_delete`
  - `lastLoginIp -> last_login_ip`
  - `lastLoginTime -> last_login_time`
  - `createTime -> create_time`
  - `updateTime -> update_time`
  - `deleteTime -> delete_time`
  - 模型选项新增：`createdAt: false`、`updatedAt: false`

## 4. 用户中心菜单乱码修复（2026-02-20 补充）

### 4.1 根因

- 之前更新菜单文案时，数据库连接字符集为 `latin1`，导致中文写入成错误字节（mojibake）。

### 4.2 修复方式

- 使用 `utf8mb4 + HEX` 方式回写文案，避免终端/会话字符集影响。
- 已更新补丁：`server/sql/patch_2026_0220_consumer_menu_alias.sql`

### 4.3 验证

- `la_system_auth_menu.id in (860,861,869)` 的 `HEX(menu_name)` 已恢复为 UTF-8 正确字节：
  - `E7AB99E782B9E794A8E688B7E4B8ADE5BF83`
  - `E7AB99E782B9E794A8E688B7E58897E8A1A8`
  - `E7AB99E782B9E794A8E688B7E7AD89E7BAA7`
