# 网址导航功能开发进度（2026-02-21）

## 1. 总体结论

- 当前项目已具备“可售卖商业版”主干能力。
- 后端核心模块已成型，前后端对接接口覆盖较全。
- 仍有少量“兼容兜底接口”未做持久化，建议进入下一阶段完善。

## 2. 后端模块覆盖（按路由分组）

`server/server/app/router/uied.js` 当前已覆盖 27 组业务模块，主要包括：

- 分类/网站/页面管理
- 热门推荐、导航菜单、友情链接、页脚、社媒、Banner
- SEO 抓取、网站提交、导出、监控、统计、操作日志
- 文章管理、文章分类、文章标签、评论管理
- WordPress 配置
- 许可证中心、交付初始化向导

已落地的商业化模块：

- 许可证中心（含签发/验签/总览）
- 功能开关能力矩阵（Free/Pro/Enterprise）
- 严格商业版模式（兼容路由可关闭）
- 交付初始化与客户包导出
- 发布前健康检查脚本

## 3. 前端公开接口覆盖（对接导航站）

`server/server/app/router/frontend.js` 已覆盖页面、网站、公开设置、分类标签、文章、投稿、AI、WordPress 兼容接口。  
文章接口链路（`/api/articles`、`/api/articles/meta/categories`、`/api/articles/meta/tags`）已可用，并保留旧路径兼容。

## 4. 当前主要缺口（建议优先级）

### P0（建议尽快补齐）

1. 网站评分接口目前为兼容返回，未持久化。  
2. 网站收藏接口目前为兼容返回，未持久化。  
3. WordPress 标签与组件公开接口目前返回空数组（缺独立配置表/服务）。

### P1（运营稳定性）

1. 商业版菜单与权限点持续去重（避免重复菜单感知）。
2. 继续完善交付自动化（客户包打包 + 清单报告自动生成）。
3. 增加商业版“升级引导文案”统一配置（前台未授权能力展示）。

## 5. 当前进度评估（面向售卖）

- 商业化基础能力：`90%+`（已可售卖）
- 导航核心业务能力：`85%+`（可稳定交付）
- 运营增强与高级闭环：`70%`（进入增强阶段）

## 6. 下一阶段开发建议（按顺序）

1. 完成评分/收藏持久化（闭环用户行为数据）。  
2. 补齐 WordPress 标签/组件配置能力。  
3. 在后台加“商业版总览”页面，直接展示健康分、版本、重复菜单告警。  
4. 继续扩展运营位模板（Free/Pro/Enterprise 三套默认模板）。
